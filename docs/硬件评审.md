# 硬件评审：原理图 vs 固件

评审对象：嘉立创工程 `ProPrj_智能药盒_2026-10-24.epro2` 的原理图（主控 MCU / 出药机构与限位 /
显示屏 / 时钟·无线 / 电源与充电 / 音频链路 / 用户 共 7 页）与 PCB 网表，对照本仓库固件
（`user/pinmap.h`、`bsp_*.c`）逐网络核对。

> 说明：以下结论均以网表 `PAD_NET` 为准（网表按“元件.焊盘 → 网络”展开），
> 并与原理图截图逐条复核。严重级别：**P0 = 板子不能用；P1 = 功能缺失；P2 = 隐患/建议**。

## 结论速览

| # | 级别 | 位置 | 问题 | 影响 |
|---|------|------|------|------|
| 1 | P0 | 电源页 U6 IP5306 | `VOUT`(pin8) 只接了 C15 22uF，**没有接到 5V 网络** | 5V 无源 → 3V3 无源 → 整板不上电 |
| 2 | P0 | 显示屏页 R46 | 屏 `LCD_SDA` 接到了 `SPI1_MISO`(PA6)，应接 `SPI1_MOSI`(PA7) | 屏幕收不到数据，白屏/花屏 |
| 3 | P0 | 时钟/无线页 U2 | ESP32 的 18 个地脚（36~53）互连成孤立网络 `$1N213`，未接 GND | WiFi 不稳定/复位，EMC 差 |
| 4 | P1 | 时钟/无线页 U12 | `FLASH_CS` 只接了 R42 上拉与 W25Q `CS#`，未接 MCU | W25Q64 不可用 |
| 5 | P1 | 电源页 R13/R14 | `BAT_ADC` 分压后悬空，未接 MCU（PA0 空置） | 无法测电池电压 |
| 6 | P1 | 电源页 D2/R21 | `VBAT` 未接 U1 pin1（空脚） | RTC/备份域无后备电源 |
| 7 | P1 | 出药页 D3/U4 | 驱动器 `VS` 由 5V 经 SS34 供给（≈4.6V） | A4988/DRV8825 等常见驱动模块无法工作 |
| 8 | P1 | 出药页 U3/U4 | 245 的 B 侧为 5V 电平，驱动器需 5V 兼容 | 选型受限，接 3.3V 驱动器会过压 |
| 9 | P2 | 出药页 R24 | `EN` 有 10k 下拉，推断驱动器 EN **低有效** | 原固件按高有效会“使能=失能” |
| 10 | P2 | 用户页 U8-U10 | WS2812B-2020 的 VDD 接 3V3（规格 3.7~5.3V） | 偏暗/偏色 |
| 11 | P2 | 电源页 R17/R19 | `CHG_STAT`/`STBY_STAT` 只是分压检测“有没有电” | 无法判断充电中/已充满 |
| 12 | P2 | 电源页 SW2/R12 | IP5306 `KEY` 串了 10k 再对地 | 按下电平不够硬，建议直接短地 |
| 13 | P2 | 电源页 U8-U10 | 状态灯串在 BAT 与 IP5306 LED 脚之间，无限流电阻 | 低电量时绿灯可能不亮 |
| 14 | P2 | 电源页 U5 | USB-C 外壳 4 脚（SHELL）全部悬空 | 屏蔽层未接地 |
| 15 | P2 | 主控页 R3/R4 | `FAULT_N` 来自 5V 域，靠 R4 1k 限流+内部钳位 | 建议改成分压更规范 |
| 16 | P2 | 显示屏页 R31 | 背光 3V3 经 10Ω 到 `LCD_BLK` | 需按屏规格确认（单颗 LED 时约 30mA） |
| 17 | P2 | 电源页 F1 | USB 输入 1A PTC，与电机/功放/充电共用 | 大电流时可能跳闸 |

## P0-1 5V 电源轨没有来源（最严重）

网表里 `5V` 网络的 16 个节点：

```
BUZZER1.1, C19.2, C20.2, C26.1, C47.1, C48.2, C49.2,
D3.2, D4.1, R19.1, U14.7, U14.8, U3.1, U3.20, U7.1, U7.4
```

全是**负载**：SY8089 降压的输入/使能、74HCT245 的 VCC、有源蜂鸣器、MAX98357A 的 VDD、
电机电源二极管、指示灯分压……没有任何一个“源”。

而 IP5306 的升压输出 `VOUT`(U6 pin8) 只连到 `C15.2`（22uF 到地），
即 `$1N87 = {U6.8, C15.2}`，与 `5V` 网络完全不相连。

后果链条：

```
USB 5V --F1--> VBUS_IN --> IP5306 VIN（只进充电，不出来）
                IP5306 VOUT = 悬空（只挂一颗电容）
5V 无源 --> U7 SY8089 无输入 --> 3V3 无源 --> MCU/屏/无线全部不工作
```

**修复建议（任选，推荐方案 A）**

A. 二极管 OR 供电（USB 与电池都能带载，推荐）：

```
IP5306 VOUT --SS34(D5)--> 5V
VBUS_IN     --SS34(D6)--> 5V      // USB 插入时由 USB 直接带载，同时 IP5306 充电
5V 加 22uF + 100nF
```

注意：IP5306 升压需要电池在位，且首次上电/插入 USB 后通常要按一下 `KEY`（SW2）才会打开
`VOUT`；如果要求“不装电池、只插 USB 也能开机”，D6 这条通路是必须的。

B. 最简（不推荐长期使用）：直接把 `U6.8 (VOUT)` 连到 `5V` 网络，接受“充电时可能掉电”。

## P0-2 LCD 数据线接错（MISO 当 MOSI 用）

网表：

```
R45: 1:LCD_SCL  2:SPI1_SCK      ✅
R46: 1:LCD_SDA  2:SPI1_MISO     ❌ 应为 SPI1_MOSI
U11(屏座): 3:LCD_SCL 4:LCD_SDA
U12(W25Q): 2:SPI1_MISO (DO)  5:SPI1_MOSI (DI)
```

ST7789 是**只写**器件，数据从 MCU `MOSI`(PA7) 进屏；现在屏的 SDA 挂在 `MISO`(PA6) 上：

- 屏永远收不到显存数据（白屏/花屏）；
- `MISO` 同时被 W25Q 的 `DO` 驱动，屏与 Flash 抢同一根线，读 ID 也会互相干扰。

**修复**：把 `LCD_SDA` 改到 `SPI1_MOSI`(PA7)——换掉 R46 的走线/飞线，屏座 4 脚改接 PA7。
固件侧无需改动（`bsp_lcd.c` 已按标准 4 线 SPI 写）。

> 备注：屏座 `LCD_BLK`(8) 由 Q1(AO3401A, PMOS) + R31 10Ω 从 3V3 高边开关，
> PB10 低电平点亮，固件已按此实现（`LCD_SetBacklight`）。

## P0-3 ESP32-C3 主接地面悬空

`$1N213 = {U2.36 ... U2.53}`（18 个 GND 焊盘，含模块中间的大地焊盘阵列），
它们只用一根导线连在一起，**没有接到 GND 网络**；模块上真正接地的只有 1/2/11/14 四个脚。

后果：模块地回路阻抗极高，WiFi 发射瞬间压降导致复位/丢包，EMC 超标。

**修复**：36~53 全部接 GND，并在模块下方铺铜、多打过孔（RF 地）。

## P1-4 FLASH_CS 悬空

```
FLASH_CS = {R42.1, U12.1}   // R42 另一端到 3V3（上拉），U12 是 W25Q64 的 CS#
```

MCU 侧没有任何连接 → Flash 永远处于未选中外的随机状态，无法访问。
固件因此把 `FEATURE_EXT_FLASH` 置 0（见 `app_config.h`），服药计划暂存内部 Flash。

**修复建议**：把 `FLASH_CS` 接到一个空闲 GPIO，推荐 **PC4**（本工程 `pinmap.h` 现以 PB4 占位，
改板后同步修改宏与 `bsp_w25q.c` 即可；PB4 是 JTAG 的 NJTRST，本工程已 `JTAGDisable`，也可用）。

## P1-5 BAT_ADC 悬空

```
BAT_ADC = {R13.1, R14.1, C16.2}   // R13 100k 到 BAT，R14 100k 到 GND，C16 100nF
```

分压中点没有接到 MCU（PA0 是空脚）。电池 3.4~4.2V → 分压 1.7~2.1V，本来正好落在 ADC 量程内。

**修复**：`BAT_ADC` → **PA0 (ADC12_IN0)**。
注意 100k/100k 的输出阻抗约 50k，STM32F1 的 ADC 采样时间需要取到 239.5 周期才准
（固件侧已预留 `FEATURE_BAT_ADC` 开关）；更稳的做法是改 47k/47k 或加运放跟随。

## P1-6 VBAT（RTC 备份）悬空

```
BT1(纽扣电池) -> D2(BAT54C) 与 3V3 二极管或 -> R21 100Ω -> VBAT = {C25.2, R21.2}
U1 pin1 (VBAT) = 空脚 ❌
```

掉电后 RTC/备份寄存器没有电源；而且固件现在的“时钟”是软件计数（见 P2-18）。

**修复**：`VBAT` → U1 pin1；配合板上已有的 LSE（X2 32.768kHz + C12/C13 6pF）即可做掉电走时。

## P1-7 / P1-8 电机驱动供电与电平

- `VS = 5V --D3(SS34)--> VS`，实际约 4.6V，且只有 C29 470uF + C30 100nF。
  常见 stepstick：A4988（VM ≥ 8V）、DRV8825（≥ 8.2V）**不能用**；
  TMC2209（≥ 4.75V）勉强可用，或选专用 5V 步进驱动（如带 ULN2003 的 28BYJ-48 方案，
  但那是 4 线相序驱动，与本板 STEP/DIR/EN 接口不匹配）。
- 74HCT245 的 B 侧是 5V 输出（VCC=5V），接 3.3V 驱动模块会过压；接 5V 逻辑模块才安全。
- `F1 = nSMD100-16V`（1A PTC）在 USB 入口，电机 + 功放 + 充电同时工作容易跳闸。

**建议**：明确选型的驱动模块（数据手册 VM / 逻辑电平），或改板给驱动单独 12V 输入。

## P2-9 电机 EN 极性

`EN = {R24.1, U3.15, U4.3}`，R24 10k 下拉。若驱动器 EN 低有效（常见），
MCU 输出高 → 245 输出高 → 驱动器被**关断**；原固件 `Motor_Enable(1)` 写高电平，
正好与预期相反。

固件已改为可配置：

```c
/* app_config.h */
#define MOTOR_EN_ACTIVE_LOW   1   /* 按实际驱动模块修改 */
```

上电后请用万用表确认 `U4.3 EN` 在“使能”时为低电平，若不是再把宏改 0。

## P2-10 WS2812 供电

WS2812B-2020 的 `VDD` 规格 3.7~5.3V，原理图接 3V3 → 亮度不足、蓝色/白色偏色。
数据电平 3.3V 反而刚好（抬高到 5V 时反而不满足 VIH）。**建议**：VDD 改 5V，
DIN 保持 3.3V（多数灯珠 0.7×VDD=3.5V 的 VIH 会不满足，可串一颗 1N4148 降压给 VDD，或选 3.3V 兼容型号）。

## P2-11 充电/待机状态是“电源存在检测”

- `CHG_STAT`：`VBUS_IN` 经 R17 100k / R18 100k 分压（C23 滤波）→ PC8，只能判断“USB 插着”；
- `STBY_STAT`：`5V` 经 R19 100k / R20 100k 分压（C24 滤波）→ PC9，只能判断“5V 有电”。

IP5306 没有状态输出脚，真实充电/电量状态只能从 LED1~3（开漏、PWM 表示电量）间接取，
或加电量计（如 CW2015）。固件目前把两脚当“电源事件”用，README 中已如实说明。

## P2-12 IP5306 按键

`SW2` 一端 GND，另一端经 `R12 10k` 接到 IP5306 `KEY`(U6.5)。
IP5306 的 KEY 内部有上拉，串 10k 后按下电平约 0.3~0.5V，多数情况下能识别，但不够硬。
**建议**：去掉 R12 或改 0Ω，按键直接对地；同时该键就是产品电源键。

## P2-13 电量指示灯

`U8/U9/U10` 直接跨在 `BAT` 与 IP5306 `LED1/2/3` 之间，没有串阻。
IP5306 的 LED 脚是恒流开漏，通常可以省电阻；但绿色 19-21/GHC 系列 Vf≈3.2V，
电池 3.0V 附近可能点不亮。**建议**串 100Ω 或换红色灯珠。

## P2-14 USB-C 屏蔽层

`U5` 的 4 个 SHELL 引脚全部空脚。建议接 GND（或 1MΩ + 1nF 并到 GND）以改善 EMC。
CC1/CC2 各 5.1k 下拉 ✅（Sink 正确），D+/D- 未用（仅充电）也符合本产品定位。

## P2-15 FAULT_N 电平

`FAULT_N` 由 5V 侧驱动器输出，经 `R4 1k` 到 `PC13`，`R3 10k` 上拉到 3V3。
PC13 不是 5V 容忍脚，靠 1k 限流 + 内部钳位（约 1.4mA，可接受）。
**建议**：改板用分压（如 10k/20k）或加 3.3V 稳压管，更规范。

## P2-16 屏背光

`3V3 - Q1(AO3401A) - R31 10Ω - LCD_BLK`。若屏背光是单颗白光 LED（Vf≈3.0V），
约 30mA，合理；若屏内是多颗串联或自带升压，R31 需按屏规格调整。
**建议**：上电后实测背光电流再定 R31。

## P2-17 电流预算

USB 5V 经 1A PTC：MCU 约 50mA、ESP32-C3 峰值 350mA、屏 40mA、功放峰值可达 1A+
（4Ω 喇叭 5V 满功率）、电机 5V 时 0.5~1A。**建议**：软件限制功放音量/占空比，
或加大 PTC 并确认 USB 电源能力。

## P2-18 时钟（固件相关）

- HSE 8MHz（X1 + C10/C11 20pF）✅ → 72MHz；
- LSE 32.768kHz（X2 + C12/C13 6pF）✅，但 VBAT 悬空（P1-6）导致掉电不走时；
- 固件当前用软件计数（`g_hour/g_min/g_sec`）实现时钟，已修复“每 10ms 加 1 秒”的 100 倍速 bug；
  即使补上 VBAT，也还需要固件接 RTC（`bsp_rtc` 待新增），否则上电仍从 08:00 起。

## 附：已确认正确的部分

- U1 全部 64 脚网名与固件 `pinmap.h` 一致（含 `PD2` 确实为空脚、`PC12` 才是 A3→EN）。
- 74HCT245：`OE#` 接地（常开）、`DIR`=5V（A→B）、A0/A4~A7 接地、B4~B7 悬空，A1/A2/A3 → B1/B2/B3 = STEP/DIR/EN。
- 按键：10k 上拉 + 100nF 去抖；限位：10k 上拉 + 100Ω + 100nF（CN2/CN3 3P 座）。
- SPI1 与 W25Q 共用：SCK=PA5、MISO=PA6、MOSI=PA7、W25Q 的 WP#/HOLD# 上拉 3V3 ✅。
- 电源：SY8089 降压 FB 分压 45.3k/10k → 3.318V ✅，20pF 前馈 C21；IP5306 电感 1uH + 22uF 输出 ✅。
- 音频：MAX98357A `SD_MODE=3V3`（(L+R)/2 单声道）、`GAIN_SLOT=GND`，I2S3 无 MCLK ✅；
  麦克风 ICS-43434 的 LR 接地（左声道）、SD 100k 下拉、VDD 经磁珠 + 1uF/100nF ✅。
- 复位/启动：NRST 10k + 100nF + 按键；BOOT0 10k 下拉 + H1 跳线到 3V3；SWD 4P 座 ✅。
- USB：CC1/CC2 各 5.1k、VBUS 经 PTC + SMBJ5.0A、D1 到地 ✅。

## 改板优先级

1. **先修 P0-1（5V 供电）、P0-2（屏 SDA）、P0-3（ESP32 地）**，否则板子无法点亮/联调。
2. 再补 P1-4/5/6（FLASH_CS、BAT_ADC、VBAT）三根线，把外部 Flash、电量、RTC 备份都打通。
3. 确认 P1-7/8 电机驱动选型与电平，再谈出药精度标定。
4. 其余 P2 属于批次改板时一并优化。
