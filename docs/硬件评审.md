# 硬件评审：最终版原理图（1_1） vs 固件

评审对象：EasyEDA Pro 工程 `智能药盒.eprj2` 的**最终版**单板 `Board1_1 / Schematic1_1 / P1`
（标题栏 `V1.0`，创建 2026-10-20，A4 单页，7 个功能块画在同一张图上）。

> 说明：`.eprj2` 是加密的 SQLite 工程，原理图内容无法从文件里导出网表，
> 本评审依据的是工程内嵌的整页预览图 + 逐块放大截图 + 用户确认。
> 标「待确认」的条目请在 EasyEDA 里核对后再改板。

## 0. 与上一版（Board1 / 两页）相比已修好的

| 项 | 上一版 | 最终版 |
|---|---|---|
| 5V 轨来源 | IP5306 `VOUT` 只接 C15，5V 网无源（板子不工作） | `VOUT` 标 `5V`，5V 有源 ✅ |

## 1. 问题清单

| 编号 | 严重度 | 位置 | 问题 | 对固件的影响 | 处理 |
|---|---|---|---|---|---|
| P0-1 | **阻断** | 时钟/无线 U2 | ESP32-C3 的 36~53 脚（GND 焊盘阵列）**只互相连在一起，没有接 GND**；只有 1/2/11/14 脚是 GND | 能启动但射频不稳、易复位 | 固件无法规避，**改板必须修**：把 36~53 连到 GND |
| P0-2 | **阻断** | 时钟/无线 U12 | W25Q64 的 `CS#`（网标 `FLASH_CS`）**没有连到 MCU 任何脚** | 外部 Flash 不可用 | 本期不使用 W25Q；改板建议接 PC10（或 PA0，二者当前空闲） |
| P1-1 | 高 | 电源 U7 | SY8089 的 `EN`、`IN` 都接 `BAT`：3V3 **只由电池产生** | 只插 USB、不接电池时整板不亮 | 固件只能提示；改板建议 `VBUS_IN` 经肖特基并到 5V，实现「插 USB 也能跑」 |
| P1-2 | 高 | 电源 D3/U7 | 5V 来自 IP5306 `VOUT`；充电时若芯片不回灌，5V 会掉 | 边充边出药可能复位 | 固件在动作前查 PC9（5V），无 5V 直接拒绝；改板同上 |
| P1-3 | 中 | 显示屏 R45/R46 | `LCD_SCL/LCD_SDA` 各串 22Ω，但 R46 另一端是 `SPI1_MISO` 还是 `SPI1_MOSI` 在预览图上无法确认（上一版接的是 MISO） | 若接 MISO，屏永远收不到数据 | 固件按 **MOSI(PA7)** 写；**请确认**，若仍接 MISO 必须飞线到 PA7 |
| P1-4 | 中 | 用户 C40~C42 | WS2812B-XF02/W 的 `VDD` 接 3V3，规格书 3.7~5.3V | 偏暗、颜色偏、个别批次不亮 | 固件亮度补偿；改板接 5V |
| P1-5 | 中 | 电源 U6 | 状态脚 PC9/PC8 是「5V 存在 / USB 存在」的 100k 分压，**不是 IP5306 的状态输出**（该芯片无状态输出，只有 LED 脚） | 只能判断供电，判断不了充电中/充满 | 固件按「供电存在」使用，文档已注明 |
| P1-6 | 中 | 主控 PC13 | `FAULT_N`（5V 域）经 R4 1k 直进 PC13，PC13 不耐 5V，靠内部钳位（约 1.4mA） | 可用但不规范 | 固件按低有效读；改板加 10k/20k 分压或换 3V3 域光耦 |
| P1-7 | 中 | 出药 D3/U4 | `VS = 5V - Vf(≈0.4V) ≈ 4.6V`；A4988/DRV8825 要求 VM≥8V，TMC2209 4.75V 起 | 选错驱动不转/丢步 | 选 5V 能跑的驱动（DRV8834、TMC2209 低压版）或把 VS 改 12V 输入 |
| P1-8 | 低 | 电源 BT1/D2/R21 | 备用电池经 BAT54C 到 `VBAT`，但 `VBAT` **没有接到 U1 的 1 脚**（仍悬空） | RTC 备份无效（本固件也直接用软件时基） | 不用管；要 RTC 就把 VBAT 接到 1 脚并焊 BT1 |
| P2-1 | 低 | 电源 U5 | USB-C 的 4 个 SHELL 脚悬空，屏蔽层未接地 | ESD/EMI 变差 | 改板接地 |
| P2-2 | 低 | 电源 U8~U10 | 三颗状态灯接在 `BAT` 与 IP5306 LED 脚之间，**无限流电阻** | 亮度不可控、LED 易过流 | 硬件问题，固件无关 |
| P2-3 | 低 | 出药 SW3 | 摄像头 5V 由 SW3 手动切换，MCU 不可控 | 不能软开关摄像头 | 需软控就换 PMOS + 空闲 GPIO |
| P2-4 | 低 | 电源 F1 | 1A PTC 同时承担充电与电机峰值 | 出药瞬间可能限流 | 大电流机构建议换 2A 或分开供电路径 |
| P2-5 | 提示 | 出药 R23/R24 | `DIR/EN` 各 10k 下拉：EN 默认低（多数驱动低有效=上电即使能） | 上电瞬间电机处于使能、有保持力矩 | 固件初始化里立刻写失能电平，已处理 |

## 2. 已确认正确、可放心使用的部分

- **电机链路**：PB8=A1→245 A0→B1=STEP(U4.1)；PB9=A2→A1→B2=DIR(U4.2)；PC12=A3→A2→B3=EN(U4.3)。
  74HCT245 `DIR` 接 5V（A→B）、`OE#` 接地（常开）、`VCC`=5V，A 侧 3.3V 输入可被 5V 驱动正确识别。
- **限位**：CN2/CN3 的 2 脚经 100Ω 到 PC6/PC7，10k 上拉 + 100nF，低有效；接插件 1=GND、3=3V3，光电/机械开关都能接。
- **电源键**：PC11 高 → Q3 导通 → IP5306 `KEY` 拉低；SW2 手动按键并联，二者互不冲突。脉宽用 120ms（数据手册要求 >30ms）。
- **USB 检测/5V 检测**：PC8、PC9 都是 100k/100k 分压到 3.3V 以内，输入安全（注意是高有效）。
- **显示**：ST7789 通过 SPI1（PA5 SCK / PA7 MOSI）+ PA4 CS / PB0 DC / PB1 RES，背光 PB10 低有效（AO3401A PMOS + 10Ω）。
- **音频/用户**：MAX98357A（I2S3：PA15 WS / PB3 CK / PB5 SD，VDD 5V，SD_MODE 3V3）；ICS-43434（I2S2：PB12/PB13/PB15）；
  蜂鸣器 PB11 经 MMBT3904；四键 PC0~PC3 上拉 + RC；WS2812 链条 PA11 → R41 330Ω。
- **时钟**：HSE 8MHz + 20pF×2 → PLL×9 = 72MHz；LSE 32.768kHz 有晶振但固件用 SysTick 软件时基（够用，误差取决于晶振）。
- **调试**：SWD（PA13/PA14）保留，固件启动即 `GPIO_Remap_SWJ_JTAGDisable` 释放 PA15/PB3/PB4 给 I2S/SPI。

## 3. 改板优先级建议

1. **P0-1**（ESP32 地焊盘）→ 不改这块板子 WiFi 基本不可用。
2. **P0-2**（FLASH_CS）→ 要存字库/日志就必须接。
3. **P1-1 + P1-2**（USB 供电路径）→ 决定「插 USB 能否单独调试」。
4. **P1-3**（LCD_SDA 到底接 MISO 还是 MOSI）→ 决定屏幕能不能显示。
5. 其余按成本择机。

## 4. 固件侧的对应处理

| 硬件现状 | 固件做法 |
|---|---|
| 无外部 Flash | `FEATURE_EXT_FLASH=0`，参数存内部 Flash 末页 |
| 5V 可能不在 | 所有动作前 `PwrHw_Is5V()`，不在位回 `ACK 5V_OFF`；上电自动按一次 KEY |
| 摄像头 5V 手动 | 文档写明「先开 SW3」，固件不做软上电 |
| 状态脚只表示供电 | 屏幕只显示 `5V` `USB` 两个指示，不声称「充电中/已充满」 |
| EN 默认下拉 | `Motor_Init()` 立即写失能电平，避免上电自走 |
| FAULT 5V 直进 PC13 | 只做输入（浮空/上拉），不推挽输出 |
