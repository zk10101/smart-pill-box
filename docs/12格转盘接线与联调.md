# 12 格转盘：接线与联调

本期电机是张大头 ZDT_X28S_V2.0 **PLC 输入版**，独立 12V 供电，自带驱动器。商品参数图标称工作电压 10-48V、脉冲输入 3.3-24V，推荐 12/24V 3A 以上电源。板上 U4 是 5V 驱动器插槽，**U4.5 `VS` 不能接 12V，也不能接电机 `V+`**。

| 主板/电源 | 电机线（按机身标签） | 说明 |
|---|---|---|
| 独立 12V 电源正极 | `V+` | 电机供电 |
| 独立 12V 电源负极 | `Gnd` | 电机供电回路 |
| U4.6 `GND` | 独立 12V 电源负极 | PLC 单端信号需共地 |
| U4.1 `STEP` | `Stp` | STM32 PB8 经 74HCT245 输出 5V 脉冲 |
| U4.2 `DIR` | `Dir` | STM32 PB9 经 74HCT245 输出 5V 方向 |
| U4.3 `EN` | `En` | STM32 PC12 经 74HCT245 输出 5V 使能；先确认极性 |
| U4.4 `FAULT_N` | 不接 | 机身的 `R/A/H` 不是已确认的 FAULT_N |
| U4.5 `VS` | 不接 | 板上约 5V，不给这台电机供电 |
| 不接 | `R/A/H`、`T/B/L` | 串口/RS485/CAN 复用脚，本期不用 |

**`Com` 暂时不要连接。**商品参数图只说明 PLC 输入电压，没有说明此版本 `Com` 是信号公共负端还是公共正端，也没有给出 `En/Stp/Dir` 的有效沿/电平。请向卖家索取 PLC 版接线页并核对：如果明确是共阴输入，`Com` 接信号 GND；如果是共阳输入，则按卖家给定的公共正端电压和输入极性接线，并可能需要调整脉冲输出极性。完成核对前不要给电机上 12V。不要根据线色代替机身印字判断。

U4 的 `EN` 网络有 10k 下拉。固件暂按“高电平使能”初始化；如果卖家确认低有效，需先确认上电时下拉导致的使能状态，再修改参数或补硬件上拉。`Com` 和 `EN` 极性未确认时，不应把电机连入正常供药机构试运行。

主板本身仍按原电源设计供电，12V 不进入主板的 5V、3V3、`VS`。STM32 检查板上 5V，因为 74HCT245 需要 5V；它**不能检测电机独立 12V 是否存在**。未接 `FAULT_N` 时，固件也无法读取该电机的故障输出。上电后先用万用表测主板 GND 与电机供电负极共地、U4.1/2/3 对地最高约 5V，再接信号线。

原理图评审还指出 ESP32-C3 的部分 GND 焊盘可能没有接地。实板上应测这些焊盘与主板 GND 导通；不导通时需要补线，否则联网稳定性不能保证。

## 标定和试转

1. 先让卖家确认 `Com` 接法、`En` 极性、脉冲有效沿，并在电机的配置工具中记录当前细分。每格机械角度为 30 度，但对应脉冲数取决于电机步距角和细分，不能从商品总览图唯一确定。
2. 上电后屏幕 `STEP/30` 显示 0，表示未标定，任何 `MOVE_SLOT` 都会被拒绝。长按 BACK 进入参数编辑；短按 UP/DN 每次增减 1，长按 UP/DN 每次增减 100；短按 OK 写入 Flash，短按 BACK 取消。先从低速和保守脉冲数试转，量出实际角度后修正。
3. ESP 每次从视觉侧取得当前格号后，向 USART1 发 `MOVE_SLOT [当前格,目标格]`。当前格与上次预测不一致时，先发 `SYNC_SLOT [实际格号]`。调试阶段可由串口工具代发，但号码必须来自人工观察，不能编造。
4. 长按 OK 急停。急停、超时或故障后位置被标记为未知，重新识别后才能继续。

完成 ACK / EVENT 表示 STM32 发完规定脉冲，不是视觉上的到位保证；后续摄像头接入时应再次识别格号并检查实际位置。完整帧见 [串口指令协议.md](串口指令协议.md)。
