# 执行机构状态机（与 `user/app/app_actuator.c` 一致）

本文件只描述**动作执行**部分。定时提醒、漏服判定、云端交互已移交上位机，
不在本固件范围内。

## 1. 状态

```
                 Act_Home()                 原点到达 + 退让完成
   ┌────────┐  ─────────────►  ┌─────────┐  ──────────────────►  ┌────────┐
   │  IDLE  │                  │ HOMING  │                        │  IDLE  │
   └────────┘  ◄─────────────  └─────────┘                        └────────┘
       │  Act_Dispense(n)          │ FAULT / 超时 / 走满未触发
       ▼                           ▼
   ┌─────────┐  走完 n×spp 步   ┌────────┐
   │ MOVING  │ ───────────────► │ ERROR  │ ◄── 任意状态：FAULT、限位止损、超时、急停
   └─────────┘                  └────────┘
        │                            │ Act_ClearError()
        └── 急停 Act_Stop() ─────────┘
```

- `ACT_ST_IDLE`：电机失能、等指令。
- `ACT_ST_HOMING`：反向找原点，命中后正向退让 `home_backoff` 步，位置清零、`homed=1`。
- `ACT_ST_MOVING`：正向发出 `粒数 × steps_per_pill` 个脉冲。
- `ACT_ST_ERROR`：电机失能 + 蜂鸣报警，`error` 说明原因。

## 2. 关键判定

| 条件 | 处理 |
|---|---|
| `Motor_IsFault()`（PC13 低） | `ACT_ERR_FAULT` → ERROR |
| 回零中顶到 PC7 终点限位 | `ACT_ERR_LIMIT_STOP` → ERROR（装反/限位接反） |
| 回零超时 `MOTOR_HOME_TIMEOUT_MS`(15s) | `ACT_ERR_NO_LIMIT` |
| 回零走满 `MOTOR_HOME_MAX_STEPS`(40000) 仍未触发 PC6 | `ACT_ERR_NO_LIMIT` |
| 出药超时 `move_timeout`（默认 8s） | `ACT_ERR_TIMEOUT` |
| 出药中顶到 PC7 | `ACT_ERR_LIMIT_STOP` |
| 未回零就出药 | 拒绝，ACK `NOT_HOMED` |
| 5V 不在位（PC9 低） | 拒绝，ACK `5V_OFF` |
| 电机正忙 | 拒绝，ACK `BUSY` |

## 3. 时间与调度

`Act_Tick()` 由主循环每 1ms 调用一次，内部只做「读引脚 + 比较时间」，
不做延时、不阻塞。运动本身完全由 TIM4 硬件 PWM 产生（PB8/TIM4_CH3），
CPU 只负责计数完成——因此屏幕刷新、串口收发都不会拖慢脉冲。

```c
/* 主循环节拍（main.c） */
1ms   : Buzzer_Tick(); Act_Tick();
10ms  : Ui_Tick();            /* 按键扫描 */
50ms  : event_poll();         /* 状态变化 → 主动上报 EVENT */
100ms : Ui_Refresh();         /* 屏幕/灯（只在字段变化时重画） */
循环  : Cmd_Tick();  IWDG_ReloadCounter();
```

## 4. 位置与精度

- 开环控制：`position += steps`，不依赖编码器；每次回零重新建立基准。
- `Act_Stop()`（急停）会停在任意步，位置**立即失效**，恢复后必须先回零；
  固件不清 `homed`，是因为上位机可能靠它判断，实际请在 `STOP` 之后重新发 `HOME`。
- 驱动器使能：每段动作结束即失能（省电、防发热），因此保持力矩约等于 0；
  如果出药轮有回弹风险，可把 `en_active_low` 反相或改固件常使能（不建议长期）。

## 5. 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `steps_per_pill` | 800 | 100~5000 | 每粒药对应微步数，随机构标定 |
| `speed_hz` | 800 | 100~4000 | 微步频率，越高越快、力矩越低 |
| `en_active_low` | 1 | 0/1 | EN 低有效（10k 下拉，常见驱动如此） |
| `dir_invert` | 0 | 0/1 | 方向取反，装反时用 |
| `home_backoff` | 40 | 0~500 | 回零后退出原点的步数 |
| `move_timeout` | 8s | 0.5~60s | 出药超时保护 |

参数存内部 Flash 末页（`0x0803F800`，magic `0x5042` + CRC16）。
首次上电写默认值，之后 `SET_PARAMS` 覆盖并掉电保持。

## 6. 上电时序

1. 电池 → U7(SY8089) → 3V3；MCU 复位，`Sys_Init` 释放 JTAG、起 SysTick。
2. `Pwr_Init()`：若 PC9 无 5V，则按 IP5306 KEY（PC11 高 120ms），轮询 800ms。
3. `Act_Init()`：读 Flash 参数 → 设速度 → 电机失能 → 记 `POWER_ON`。
4. 主循环开始，看门狗约 4s（`IWDG_RELOAD_VALUE=2500` @40kHz/64）。
5. **此时未回零**，屏幕显示 `IDLE` + `!HOMED`，必须等 `HOME` 后才允许出药。

## 7. 日志

环形 32 条（`LOG_ENTRIES`），每条 `{ev, a, b, t_ms低16位}`，
记录上电、回零成功/失败、出药起止/中止、故障、急停、清错、参数保存。
`GET_LOG(n)` 返回最新 n 条（n≤20，帧长限制）。
