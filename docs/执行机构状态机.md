# 12 格转盘执行状态机

STM32 不负责定时、联网或视觉识别。ESP32-C3 每次发 `MOVE_SLOT [当前格,目标格]`，格号范围 1..12。电机只按一个方向转动，跨越 12→1 时按一格处理；无原点开关时不执行旧 `HOME`。

| 状态 | 条件 | 动作 / 下一状态 |
|---|---|---|
| IDLE | 上电 | 当前格未知；等 ESP 提供格号，未标定时不运动 |
| IDLE | 收到 `MOVE_SLOT` | 校验格号、预测位置、标定值和板上 5V；通过后发指定 STEP 脉冲，进入 MOVING |
| IDLE | 当前格等于目标格 | ACK OK，不发脉冲，记录预测格号 |
| MOVING | STEP 脉冲发完 | 停机，预测格号设为目标格，回 IDLE，回报完成事件 |
| MOVING | STOP / 长按 OK | 立即停机，格号作废，回 IDLE |
| MOVING | 超时 / FAULT_N 有效 | 停机，格号作废，进入 ERROR |
| ERROR | CLEAR_ERROR / 短按 BACK | 回 IDLE；须重新识别格号 |

若新识别的格号与上次预测不符，`MOVE_SLOT` 返回 `POS_MISMATCH`，ESP 可以用 `SYNC_SLOT [实际格号]` 显式更新，再重新下发目标。重复发送已完成的旧 `MOVE_SLOT` 会因当前位置不符而被拒绝。`SYNC_SLOT` 只能在空闲且无故障时执行。

每格脉冲数必须现场标定；`steps_per_slot=0` 表示未标定，固件不会转动。电机独立 12V 电源未被 STM32 监测，且 U4 `FAULT_N` 未连接电机故障输出，因此“完成”仅保证已发送指定数量脉冲。真正到位和药已取走应由之后的视觉流程确认。
