# 智能药盒执行机构固件

主控为 STM32F103RCT6，使用 Keil MDK 和 STM32 标准外设库。板载 ESP32-C3 负责联网并接收云端指令；STM32 只执行 12 格转盘动作、回报脉冲完成和故障，并提供本地显示与急停。摄像头识别及“药已取走”判断由其他模块负责，本仓库暂不接入。

当前电机是张大头 X28S_V2.0 PLC 输入版，自带驱动，独立 12V 供电。ESP 每次发送视觉识别的当前格号和目标格号，STM32 顺时针转动相应格数。没有经过标定的每格脉冲数时，固件拒绝运动。

## 使用流程

1. 按接线文档核对 PLC 版电机的 `Com`、`En`、`Stp`、`Dir` 极性。**不要把 12V 接到主板 U4.5 `VS`。**
2. 在电机配置工具中确认细分和脉冲输入设置。长按主板 BACK 进入屏幕参数编辑，调好每格 30 度对应的 STEP 脉冲数后按 OK 保存。默认值为 0，禁止未标定运动。
3. ESP32-C3 从摄像头或人工调试输入取得当前格号，向 STM32 USART1 发送 `MOVE_SLOT [当前格,目标格]`。当前格与上次完成后记录的预测位置不一致时，先发送 `SYNC_SLOT [实际格号]`。
4. STM32 返回 ACK；脉冲发完后发送完成事件。ESP 后续应复查实际格号，不能把脉冲完成等同于药片取走。

旧版 `DISPENSE`、`HOME`、`CAM_TRIGGER` 命令已停用。长按 OK 急停，短按 BACK 清故障；急停和故障后位置未知，须重新识别。

## 构建

```powershell
& 'D:/Keil_v5/UV4/UV4.exe' -r 'smart-pill-box.uvprojx' -j0 -o 'build.log'
```

主代码在 `user/app/`，引脚和外设操作在 `user/bsp/`。电机 STEP 为 PB8/TIM4_CH3，经 74HCT245 输出到 U4.1；DIR 为 PB9 到 U4.2；EN 为 PC12 到 U4.3。串口 USART1 为 PA9/PA10，115200-8N1。硬件与接口层映射见 [三层架构与接口](docs/三层架构与接口.md)。
